# Postmortems

Blameless reviews of real incidents on the GPU sessions. Each states impact,
timeline, cause, what changed and its evidence. Session IDs (B-00x) and
decision IDs (D-00xx) refer to the maintainer's budget and decision logs,
which are private; every change they led to is a public pull request.
